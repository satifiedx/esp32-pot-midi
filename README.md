# esp32-pot-midi

Педаль на потенциометре + ESP32-C3 Super Mini → MIDI → FL Studio (или любая DAW). Вся настройка в GUI на ПК, с пресетами.

У ESP32-C3 нет USB MIDI, поэтому плата шлёт сырое значение АЦП по USB-сериалу, а `pot_bridge.exe` превращает его в MIDI и шлёт в виртуальный порт [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html).

```
педаль -> ESP32-C3 (raw 0..4095) -> USB COM -> pot_bridge.exe -> loopMIDI -> FL Studio
           калибровка -> позиция 0..100% -> пресет -> полутоны -> Pitch Bend / CC
```

## Железо

- ESP32-C3 Super Mini
- Потенциометр B50K: средняя ножка → GPIO3, крайние → 3.3V и GND

## Прошивка

Плата: **ESP32C3 Dev Module**, **USB CDC On Boot = Enabled**.

```bash
arduino-cli core install esp32:esp32
arduino-cli compile --upload -p COM4 --fqbn esp32:esp32:esp32c3:CDCOnBoot=cdc pot_midi
```

Если `Failed to connect`: зажми BOOT, переподключи USB и повтори.

- `pot_midi/` шлёт сглаженное значение АЦП текстом, по строке, примерно 100 раз в секунду: среднее из 32 замеров, медиана из 5, мёртвая зона 3. Раз в 0.5 с повторяет текущее значение.
- `pot_test/` для проверки: печатает сырые значения раз в 50 мс.

## Запуск

1. Поставь и запусти loopMIDI, создай порт (кнопка **+**).
2. Воткни плату.
3. Запусти `pot_bridge.exe` из [Releases](../../releases) (или `python pot_bridge.py`). Плату (USB VID 303A) и порт loopMIDI он находит сам и переподключается, если что-то отвалилось. Статус видно вверху окна.

`config.json` (калибровка, последний пресет, режим вывода) и `presets.json` лежат рядом с exe.

## Окно

**Калибровка.** Жми «Калибровать (5 с)» и качай педаль от упора до упора. Если работает наоборот, ставь «Инверсия».

**Пресет.** Все изменения применяются сразу и сохраняются сами.

| Параметр | Что делает |
|---|---|
| Начало / конец хода, % | на каком участке хода педали меняется выход. 0–50: к половине хода уже максимум |
| Мёртвая зона, % | в начале хода выход стоит ровно в стартовом значении, чтобы «ноль» возвращался без отпускания до упора |
| Значение в начале / в конце, пт | выход в полутонах, −24…+24 |
| Кривая | влево быстрее в начале, вправо быстрее в конце, по центру линейно |
| Шагать по целым полутонам | округляет выход до целых |

Кнопки «Сохранить как…», «Переименовать», «Удалить». Пресеты переключаются из списка или клавишами **1–9**, пока окно в фокусе.

Стартовые пресеты: «0→+12 к половине», «0→−12 к половине», «0→+24 полный», «0→−24 полный», «−24…+24 полный».

**Вывод в MIDI.**
- **Pitch Bend 14-bit**, по умолчанию. Шкала −24…+24 линейно на 0…16383, центр 8192 = ровно 0 полутонов.
- **CC** (номер настраивается), запасной. 7 бит: 0 полутонов = CC 64, это примерно +0.19 пт в FL.

## FL Studio

1. **F10** → MIDI → **Input**: выбери `loopMIDI Port`, **Enable**. В Output его не включай.
2. В плагине правый клик по параметру (−24…+24) → **Link to controller…** → качни педаль → **Accept**. В FL больше ничего настраивать не надо.

## Сборка exe

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --name pot_bridge pot_bridge.py
```
